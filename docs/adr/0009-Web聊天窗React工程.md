# ADR-0009：自带 Web 聊天窗——独立 React 工程，定位示例集成

- 状态：已接受
- 日期：2026-10-22

## 背景

第一版对话入口选择自带 Web 聊天窗；项目定位是开发者框架（ADR-0001），聊天窗是示例集成而非产品本体。

## 决策

- `web/` 目录承载**独立 React + Vite 工程**，构建产物由 FastAPI 静态托管。
- 聊天窗演示完整接入路径：签名 token 开会话（demo 模式用 MockIdentityProvider）、SSE 渲染、工具调用状态展示。
- 渠道方可以完全不用它，只消费 HTTP/SSE API。

## 备选方案

- **原生 JS 单文件（无构建）**：否。用户明确选择 React 工程化路线，观感与可维护性优先，接受引入前端工具链。

## 影响

- 正面：聊天窗可独立演进；对熟悉 React 的接入方是可改造的起点。
- 负面：仓库含两条工具链（uv / npm），CI 与贡献门槛略升——用 CI 分开两条流水线缓解。
