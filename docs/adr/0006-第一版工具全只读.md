# ADR-0006：第一版工具全部只读

- 状态：已接受
- 日期：2026-10-22

## 背景

客服 Agent 天然会走向"发起退款""创建售后单"等写操作。写操作意味着幂等、确认、审计一整条复杂度链。

## 决策

- 第一版工具**全部为只读查询**：`orders__query_orders`、`orders__get_order`、`aftersales__list_aftersales`、`aftersales__get_aftersale`。
- 架构上**不为写操作预付任何复杂度**——不预留审批钩子、不做确认协议。

## 备选方案

- **只读 + 预留写操作审批钩子**：被否。违反"不为假设性需求设计"，等真实写需求出现时按其真实形态设计（届时写操作定义为独立 ToolSet，带确认流程与幂等键）。

## 影响

- 正面：安全面最小（无副作用即无回滚问题）；接口最简。
- 负面：第一版只能答疑不能办事；写操作是明确的路线图项，文档中如实标注。
