# ADR-0008：对话接口采用 SSE 流式

- 状态：已接受
- 日期：2026-10-22

## 背景

自带聊天窗（ADR-0009）需要对话体验；客服场景下长回答整段等待观感差。

## 决策

- `POST /chat` 返回 **SSE 流**，事件类型固定为：
  - `message.delta`：token 级增量文本；
  - `tool_call.started` / `tool_call.completed`：工具调用生命周期（含工具名，便于前端展示"正在查询订单…"）；
  - `done`：本轮结束（含用量统计）；
  - `error`：结构化错误。
- 一次请求 = 一轮完整 Agent 循环（模型回复 ↔ 工具调用往复），循环内所有事件走同一条流。

## 备选方案

- **整段返回 JSON**：否。作为内部调试便利保留（非流式开关），但不是一等接口。

## 影响

- 正面：体验达标；前端与 Agent 循环解耦（渠道方自行实现任意 UI）。
- 负面：接口复杂度略高，需要事件 schema 文档与示例。
