# ADR-0010：工程基线——MIT / Python 3.12+ / uv / FastAPI / docker-compose

- 状态：已接受
- 日期：2026-10-22

## 决策

| 项 | 选择 | 理由 |
|---|---|---|
| 开源协议 | MIT | 最宽松，框架类项目传播最优 |
| Python 基线 | 3.12+ | 用户拍板；async 生态成熟 |
| 依赖管理 | uv + pyproject.toml | 标准化、速度快、社区主流 |
| Web 框架 | FastAPI + uvicorn | 既定技术栈，原生 async，SSE 支持好 |
| 部署 | docker-compose 一键起 | 应用 + demo 数据；多实例/K8s 后置 |
| 包结构 | 单包 `shoppilot`，领域以 contrib 子包组织 | 先单包，生态需要时再拆分发包 |

## 影响

- Python 3.12 基线意味着放弃更老的部署环境，写进 README 系统要求。
- 单包策略下，领域插件与核心同仓库演进，接口稳定性靠 ADR 与版本号约束。
